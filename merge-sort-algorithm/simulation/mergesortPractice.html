• A default array is shown when the page loads. You can use it directly or change the size and values as you like.
  • To use your own array, select the length and enter numbers separated by commas (for example: 5, 3, 8, 1).
  • Click Setup to update the array and get ready for sorting.
  • Click Next to see each step of the merge sort process. The array will be split and merged step by step.
  • Watch the Observations box for comments explaining what is happening at each step.
  • Click Reset to start over with a new or the same array.
